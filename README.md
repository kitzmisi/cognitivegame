# Predictive Index kognitív gyakorlóteszt

50 kérdéses, 12 perces gyakorlóteszt (numerikus, verbális, logikai és mintafelismerő feladatok).
Egyetlen fájl (`index.html`), telepítés vagy szerver nélkül működik.

A kérdések saját készítésűek, hasonló stílusban, mint a valódi teszt, de nem az eredeti tesztből valók.

## Használat
Nyisd meg az oldalt, nyomd meg az Indítás gombot, és válaszolj minél gyorsabban.
A végén látod a pontszámot és a helyes válaszokat magyarázattal.
